# VoiceOverの修正と実機確認（Issue #56）

## 現時点の状態

コード修正と自動検査の結果、および実機での確認結果を分けて記録する。`--voiceover-layout` はDEBUGビルドで代替UIを自動操作するための引数であり、VoiceOverの音声・フォーカス移動・ダブルタップを再現するものではない。実機確認の記録が埋まるまでIssue #56は未完了とする。

## 修正内容

- 地図の道路・POI・注釈をVoiceOverのフォーカス順から除外する。地図は描画を維持し、目的地は検索・保存済み一覧から選ぶ。
- VoiceOver使用時は、通行不可区間を検索可能な道路一覧から選択・解除できる。位置情報があれば現在地に近い順にし、取得できない場合はその旨を示す。登録済み区間の解除には確認を挟む。
- 目的地パネルはボタンのダブルタップ、ローターの値調整で展開・縮小できる。縮小時は目的地の要約だけを読み上げ対象にし、隠れた操作には移動しない。
- 検索からの選択、施設カード、ナビ開始、設定・登録画面から戻る際のフォーカスを指定する。
- 保存済み目的地と道路区間の選択状態を値として伝える。設定のスイッチは標準のオン・オフ読み上げを使う。

- カメラ・地図ナビの停止確認は、明示的な取消ボタンを持つ標準アラートを使用する。
- 設定・登録・確認ダイアログ・全面カメラの表示中は、背後の画面を明示的に読み上げ対象から除外する。

## 実機での確認手順

確認する端末・iOS・ビルドを記録し、修正ブランチまたは統合確認用ビルドをXcodeから実機へRunする。シミュレーターや旧ビルドでの結果を実機確認として扱わない。VoiceOver使用中に「道路を一覧から選ぶ」が表示されることでも修正版を識別できる。

実機の設定 > アクセシビリティ > VoiceOverをオンにする。通常の左右スワイプでフォーカスを移し、ダブルタップで実行する。スクロールは3本指のスワイプを使う。パネルはダブルタップで切り替えられるので、通常の指のドラッグに頼る必要はない。

現地へ移動せずUIを評価する場合、アプリの「設定」最下部にある「バージョン情報」を3秒以内の間隔で7回操作してDeveloperModeを開き、模擬位置を有効にする。模擬位置・模擬報告は実データとは別である。位置が選択地域内で照合され、目的地までの経路確認が表示されたことを確認する。実際の移動はこのUI評価の対象外。

1. **地図ホーム**：画面を見ずに一周する。検索・設定・通行不可登録へ到達できる。道路やPOIを延々と読み上げない。
2. **検索・選択**：検索欄に施設名を入力し、候補を選ぶ（オフラインのUI確認では座標を入力する）。目的地名が読み上げられ、選択状態が分かる。検索を閉じる・入力消去も識別できる。
3. **目的地パネル**：展開・縮小をダブルタップで各2回行う。縮小状態では隠れたナビ開始ボタンへ移動しない。ローターの値調整でも展開・縮小できる。再展開後、経路と案内開始へ到達できる。
4. **ナビ開始・終了**：ナビ開始の確認ダイアログを開く。背後の操作へフォーカスが移らない。取消後は開始操作へ戻れる。再度開始し、次の案内と終了ボタンを読み上げ、終了確認から地図へ戻る。
5. **通行不可登録**：「道路を一覧から選ぶ」を開く。道路名・区間の説明・距離・選択状態を確認する。必要なら道路名や区間IDで検索する。1区間を選択・解除・再選択し、完了から登録画面へ戻る。
6. **登録確認・修正**：登録対象の区間数が選択数と一致することを読み上げで確認する。「戻って修正」で道路選択へ戻り、区間数を変更して再確認する。模擬領域で登録し、通知を閉じた後も必要な操作にフォーカスできる。登録済み道路の解除確認を開き、取消と解除をそれぞれ確認する。
7. **設定**：スイッチの名前と現在値を聞き、1項目を変更・元に戻す。「完了」で地図の設定ボタンへ戻れる。評価後はDeveloperMode・模擬位置を終了する。

操作は目視せずに実施し、必要なら別の人が画面・録画を記録する。途中で見ないと進めない操作があれば、その箇所を未達として残す。

## 2026-11-09 追加確認ブランチ

`feature/issue-56-voiceover-validation`で、カメラ画面の初期フォーカスと設定・登録・停止取消からの復帰先、地図ナビの登録画面・終了取消からの復帰先を明示した。`testAccessibleCameraControlsAndModalReturn`でカメラの操作要素の説明とモーダル終了後の操作継続を自動確認する。自動検査は実機VoiceOverの代替ではない。

実機確認では、カメラから設定を開いて閉じた後と、停止を取り消した後に「メニュー」へ戻ること、地図ナビの終了を取り消した後に「終了」へ戻ることも確認する。

#60のUI整理後は、検索窓下の実験地点チップを使用しない。通信に依存しないUI確認は検索欄に `33.8848401,130.8809004`（小倉の道路上）を入力して検索する。選択地点名は「指定した座標」と表示される。
