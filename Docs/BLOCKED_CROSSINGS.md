# 通行不可区間の通過・横断を避ける経路検索

登録された区間IDの除外に加え、同一階層または階層不明の道路について次を検索から除外する。

- 登録区間と途中で交差・重複する道路区間。
- 登録区間上の交差点を途中で通り抜ける経路。交差点を出発点または案内終点とする場合は、登録区間を使わず離れる・手前で終えることを許容する。
- 道路外の現在位置から道路へ接続する直線が登録区間を横切る候補。
- 道路上の案内終点から選択地点までの未確認の直線が登録区間を横切る候補。

道路網に階層が数値で明記され、異なる階層で交差する場合は、幾何的な交差だけで閉鎖しない。共有接続点は地続きの接続として扱う。階層が不明な道路や、階層を持たない道路外接続について、立体交差だと推定して通過を許可しない。

交差する道路は区間全体を除外するため、交差点手前の一部分だけを利用する経路も保留になる場合がある。迂回できる候補がない場合は経路なしを返し、直線接続や別の区間IDを使った横断へフォールバックしない。表示・ナビ開始の前にも制約を検査する。

派生した除外区間は報告として保存しない。画面上の登録区間数と `excludedSegmentIDs` は、利用者が実際に登録した区間IDのままとする。登録解除後は派生した制約も解除する。

## 検証

`swift test` の既存テストに加え、`BlockedCrossingTests` で次を確認する。

- 共有交差点を通過する経路の迂回、迂回路がない場合の保留。
- 接続点を共有しない幾何的な交差、同一直線上の重複。
- 明記された異層交差と、階層不明の交差。
- 出発位置・目的地の部分区間と一括候補選択での交差点通過。
- 道路外接続・目的地までの未確認区間の横断。
- 元の登録数の保持と、登録解除後の短い経路の復帰。

これは保存済み道路形状・接続・階層に対する制約であり、通行可能性や施設入口を現地確認する機能ではない。道路データ自体の位置ずれ・欠損は残る。
