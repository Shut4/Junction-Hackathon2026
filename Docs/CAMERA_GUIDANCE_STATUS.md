# カメラ上部のナビ・危険表示と音声（Issue #75 / #77）

- 青い「ナビ」欄は、AR矢印と同じ進行方向を「直進」「左へ」等で表示する。方位を確定できない場合は「確認中」とし、方向を推測して表示しない。
- 「危険」欄はhigh/criticalの情報を優先度・距離順で1件表示する。緊急は赤の「止まって」、注意はオレンジの「段差注意」「ポールに注意」等にする。ランドマーク情報を危険欄に混ぜない。
- 検出がない場合は「検出なし」、認識が停止中の場合は「認識停止」と表示する。安全確認済みとは表現しない。
- 標準サイズでは横並び、大きなアクセシビリティ文字サイズでは縦並びにして、カメラと下部操作を確保する。
- VoiceOverでは「ナビ」「危険」の各欄を独立した要素とし、危険欄の値は短縮前の情報を読み上げる。

## 音声と振動

カメラの危険・注意は自動で読み上げず、iPhoneと白杖の振動で伝える。警告音と連続ブザーも出さない。画面上の危険欄は維持し、利用者がVoiceOverでフォーカスした場合は詳細を確認できる。危険イベントによってナビの発話を止めたり、5秒間保留したりしない。

自動の道案内は冒頭に「ナビ」を付ける。周辺の目印音声よりキュー優先度を高くし、音声合成で目印を説明中ならナビへ切り替える。VoiceOver使用中はVoiceOverのアナウンス経路を使い、音声合成との二重再生を防ぐ。危険内容は両方の出力経路の手前で除外するため、従来形式の危険通知からも発話しない。

停止と判定する距離の既定値は0.5m、注意は0.5mを超え0.8m以下とする。0.8mを超える検出は警告しない。距離不明・非数・ゼロ以下の距離は注意／危険に分類せず、灰色の「距離確認中」と表示する。直前の既定値（停止0.6m・注意1m）を含む以前の既定値に一致する保存値は移行し、それ以外のカスタム値は保持する。この閾値変更の実環境での検出性能は未測定。

方角を確定できない状態が3秒続いた場合は「ナビ、方向を確認中です。」と一度伝え、復帰後は方向を読み上げる。音声案内の有効設定はAR矢印の表示設定に依存させない。

中央下の音声ボタンとメニュー内の「周囲を読み上げ」は削除済み。危険の警告音スイッチと開発用の警告音・ブザー調整も削除し、振動の調整は維持する。

## 検証範囲

GuidanceStatusTestsは、危険の全優先度で自動発話がないこと、危険通知が続いてもナビ音声を抑制しないこと、目印よりナビを先に扱うこと、表示文の短縮と詳細文の保持を確認する。UIテストはVoiceOver代替レイアウト、模擬ポール検出中のナビ・危険の同時表示、設定画面からの警告音スイッチ削除を確認する。実機での振動・VoiceOverの聴取確認は別途必要で、自動検査を実際の聴取結果とは扱わない。

## 自動経路探索の失敗（Issue #79）

位置情報取得待ちからの自動再探索、および経路逸脱による再探索では、失敗ダイアログを表示しない。同じエラーは復旧または案内停止まで繰り返し読み上げず、最初の発生時だけ「ナビ、経路が見つかりません。地図で経路を確認してください。」と伝える。利用者が明示的に経路を確認・開始した場合は詳細ダイアログを残す。

カメラのナビ欄は失敗時に「経路なし」、位置待機中は「位置確認中」と表示する。VoiceOverで失敗欄へフォーカスしたときは詳細な原因を読み上げる。探索成功・案内停止・目的地解除で失敗状態を解除する。道路の接続や通行不可制約は変更しないため、実際に接続がない経路を案内可能にはしない。報告された経路自体の失敗原因は目的地・実機ログが取得できておらず未確定。

UI回帰テストはシミュレータ専用の切断道路を使用し、カメラ表示後の位置取得による自動失敗でダイアログが出ないこと、明示再検索では原因を表示すること、目的地解除で失敗表示が消えることを確認する。このテスト用模擬位置は実機・Releaseではコンパイルされない。

連続ブザーの距離の保存設定は0.4m（従来0.5m）へ移行するが、無効化済みのブザー出力は再開しない。検知不能・通信切断の扱いは変更しない。

## 誤った注意表示と至近距離の判定（Issue #90）

有効な深度の処理下限、および頭上・歩ける範囲の最小前方距離を0.1mに統一する。これは処理上の受け入れ範囲であり、センサーが0.1mまで正確に測れるという保証ではない。従来の既定値（頭上0.3m、歩ける範囲0.5m）に一致する保存設定は移行する。深度を取得できない場合や0.6秒以上更新されない場合は古い深度表示を解除し、確認中として扱う。

物体の距離は検出枠の中央70%内の深度の20パーセンタイルから求める。枠下端の背景を拾って近い物体を遠いと誤認しないようにする。0.5m以内の面は、平面であることや枠下端が床から離れていることだけで除外しない。側方の段差・障害物の通知にも前方距離の上限を適用する。頭上の注意がある場合でも、より近い足元の危険を抑制しない。

再現テストは距離不明、0.1〜0.5mの障害物、検出枠下端の背景、遠方の側方段差、頭上注意と足元危険の重複、設定移行を対象とする。実際の誤検知・検知漏れの改善効果は実機で確認する必要がある。
