# カメラ上部のナビ・危険表示と音声（Issue #75 / #77）

- 青い「ナビ」欄は、AR矢印と同じ進行方向を「直進」「左へ」等で表示する。方位を確定できない場合は「確認中」とし、方向を推測して表示しない。
- 「危険」欄はhigh/criticalの情報を優先度・距離順で1件表示する。緊急は赤の「止まって」、注意はオレンジの「段差注意」「ポールに注意」等にする。ランドマーク情報を危険欄に混ぜない。
- 検出がない場合は「検出なし」、認識が停止中の場合は「認識停止」と表示する。安全確認済みとは表現しない。
- 標準サイズでは横並び、大きなアクセシビリティ文字サイズでは縦並びにして、カメラと下部操作を確保する。
- VoiceOverでは「ナビ」「危険」の各欄を独立した要素とし、危険欄の値は短縮前の情報を読み上げる。

## 音声

両方の発話経路（VoiceOverアナウンス／AVSpeechSynthesizer）へ渡す前に種別を付ける。

| 種別 | 例 |
|---|---|
| 道案内 | ナビ、左へ。 |
| 注意（high） | 注意、前方にポール。 |
| 即時の危険（critical） | 危険、目の前にポール。 |
| 周囲の目印 | 周囲、前方に横断歩道。 |

停止警告（critical）だけが古い経路音声を無効化し、最後の停止警告から5秒間ナビ音声を抑制する。注意（high）はナビ音声を消さず、割り込まずに順番に読み上げる。VoiceOverでも停止警告だけを高優先度・割り込みとし、注意とナビはキューに入れる。種類は両方の音声経路で冒頭に「ナビ」「注意」「危険」を付ける。

停止と判定する距離の既定値を、物体・頭上・足元で1mから0.6mへ変更した。0.6mを超え1m以下では注意を残し、1mを超える検出は警告しない。距離不明は注意とする。連続ブザーは従来の0.5m以内を保つ。以前の既定値に一致する保存値は移行し、それ以外のカスタム値は保持する。この閾値変更の実環境での検出性能は未測定。

方角を確定できない状態が3秒続いた場合は「ナビ、方向を確認中です。」と一度伝え、復帰後は方向を読み上げる。音声案内の有効設定はAR矢印の表示設定に依存させない。停止警告中は方向通知を保留し、解除後に現在の方向を再確認する。

中央下の音声ボタンとメニュー内の「周囲を読み上げ」は削除した。自動のナビ・注意・危険音声と、上部カードのVoiceOver読み上げは残す。

## 検証範囲

GuidanceStatusTestsは、種別接頭辞、危険直後の道案内抑制と再開、繰り返し危険通知、表示文の短縮と詳細文の保持を確認する。UIテストは通常・最大文字サイズ、VoiceOver代替レイアウト、模擬ポール検出中のナビ・危険の同時表示を確認する。実機VoiceOverで聞き分けを確認した記録は別途必要で、自動検査を実際の聴取結果とは扱わない。


## 自動経路探索の失敗（Issue #79）

位置情報取得待ちからの自動再探索、および経路逸脱による再探索では、失敗ダイアログを表示しない。同じエラーは復旧または案内停止まで繰り返し読み上げず、最初の発生時だけ「ナビ、経路が見つかりません。地図で経路を確認してください。」と伝える。利用者が明示的に経路を確認・開始した場合は詳細ダイアログを残す。

カメラのナビ欄は失敗時に「経路なし」、位置待機中は「位置確認中」と表示する。VoiceOverで失敗欄へフォーカスしたときは詳細な原因を読み上げる。探索成功・案内停止・目的地解除で失敗状態を解除する。道路の接続や通行不可制約は変更しないため、実際に接続がない経路を案内可能にはしない。報告された経路自体の失敗原因は目的地・実機ログが取得できておらず未確定。

UI回帰テストはシミュレータ専用の切断道路を使用し、カメラ表示後の位置取得による自動失敗でダイアログが出ないこと、明示再検索では原因を表示すること、目的地解除で失敗表示が消えることを確認する。このテスト用模擬位置は実機・Releaseではコンパイルされない。
