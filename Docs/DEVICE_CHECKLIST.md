# 実機・現地評価チェックリスト

対象: iPhone 16 / iOS 27.0。屋外評価は同行者を伴い、対象経路を事前に歩いて確認する。災害現場で評価しない。通行不可は実際に道路を封鎖する操作ではなく、アプリ内の登録を使用する。

## 道路・現地

- [ ] 上部検索欄に直接入力し、補完候補・検索結果を操作。右端の丸×で入力を消去し、空欄で再度タップすると検索を閉じる。VoiceOverの読み上げが「入力を消去」から「検索を閉じる」に変わることを確認。任意の避難先を名称検索・地図長押し・直接座標・保存済み一覧から選択。範囲外・接続点なしは案内不可と明示。
- [ ] 道路終点候補を利用者が確認し、選択施設への入口・最後の接続・受入状況を同行者と確認。選択地点と道路終点を混同しない。
- [ ] 小倉駅南側、京町、魚町の実験接続点を現地で特定。実際の入口を確認して、必要なら目的地を修正。
- [ ] 使用する全区間の歩道、横断、階段、デッキ、入口、access条件を確認。地上・高架・橋下を区別。
- [ ] OSMとMapKitの位置差を測定。点字ブロック、横断信号、路面状況を地図データから推定しない。
- [ ] 二つ以上の迂回を実際に確認。ネットワークの端を越える経路は使用しない。
- [ ] 1区間閉鎖で迂回、一方通行、目的地への全接続閉鎖で経路なし。

## 選択・保存

- [ ] 初期表示の地図で道路をタップ、再タップ解除、地図移動/拡大縮小、候補確認、取消、やり直し、複数連続区間。VoiceOver用一覧は補助操作から到達。
- [ ] 並行道路、歩道と車道、交差点、指のぶれ、拡大率、範囲外、データなし。
- [ ] 高架・橋下・階段は初期データから除いた区間がある。該当区間の対応を追加せずに選択成功と扱わない。
- [ ] 候補が曖昧なとき、地図・一覧の候補確認で確定できる。離れた区間は登録不可。
- [ ] なぞった一部分を含む区間全体が、赤い実線・明るい縁・×・一覧に一致する。
- [ ] 地図と一覧が同じ区間IDを示し、登録前に両端・距離・範囲を確認できる。
- [ ] 5項目の報告、一括保存、直後の迂回、再起動後の保持。
- [ ] DeveloperModeで保存・読み込みエラーを注入。破損・版不一致は自動テストと別コピーの実験データで確認。実報告を破損させない。
- [ ] 古い報告が自動解除されない。解除と模擬リセットの確認対象が一致する。

## 実位置・音声

- [ ] 権限未決定・拒否、精度不足、古い更新、範囲外、複数道路候補で保留。
- [ ] 異なる新しい位置サンプルが3回継続した道路候補を使う。静止時に確認が進まない場合も未確認とする。
- [ ] 不連続な位置ジャンプで案内を保留。経路逸脱は信頼できる位置の継続で再検索。
- [ ] 信頼できる移動方向がないとき、左右案内を出さない。実コースに沿う移動時だけ曲がる案内を確認。
- [ ] 経路上の報告登録で古い案内を破棄し、変更文か経路なしを発話。
- [ ] 再読み上げ・停止・優先通知・同時発話防止。停止後の遅いカメラ処理から音声が復活しない。
- [ ] アプリ音声とVoiceOverが重ならないか、イヤホンと本体スピーカーで聞き取り確認。
- [ ] 発話開始コールバックと実際に耳へ届く時刻を区別。端末外で測定する場合は別途実験方法を明記。

## カメラ評価

- [ ] 背面カメラの向き・画角・首掛け固定。揺れ、遮蔽、逆光、低照度。
- [ ] ポール、階段、段差、車止め、人、自転車について、対象が見える機会と見逃しを同行者が数える。
- [ ] 継続検出、消失、再出現、複数対象、クラスの揺れ、ID対応付けの失敗。
- [ ] 短い定型通知のみ。距離、水深、幅、安全、左右回避を断定しない。
- [ ] 通知回数/分、誤警告/分、見逃し数、同対象の繰り返し、抑制数を記録。
- [ ] 推論・通知決定・発話開始コールバックの遅延。中央値と上位値、フレーム落ち、メモリ。
- [ ] 10分以上の同じ条件で、開始・終了電池、熱状態、体感発熱を記録。端末の電池パーセントは粗い測定である。
- [ ] カメラ停止・モデルなし・認識エラーでも道路機能が動く。カメラ権限拒否中はアプリ本体を表示せず、許可画面から先へ進めない。

## アクセシビリティ・通信

- [ ] 通知の許可確認後は許可・拒否のどちらでも位置情報ページへ自動で進む。通知を確認せず「次へ」で進む操作も確認。中断したページから再開。
- [ ] 位置情報・カメラは許可後に自動で次へ進む。拒否時は「許可なし」と理由、iOS設定ボタンを読み上げ、「次へ」が表示されない。設定で許可して戻ると進む。
- [ ] チュートリアル完了後に位置情報またはカメラの許可を取り消すと、再起動・アプリ復帰時に該当する許可画面が出る。再許可まで地図・登録・案内は使えない。通知拒否でもアプリ内音声は使える。
- [ ] 全面カメラの上下操作カード、地図への復帰、再読み上げ、登録、カメラ停止、案内停止、設定へ到達。
- [ ] VoiceOverのみで目的地、経路確認、開始・停止、区間選択・登録、再読み上げ、カメラ、状態、シート展開・縮小を操作。
- [ ] 読み上げ順、ボタン名・状態・説明、確認後のフォーカス。
- [ ] 最大Dynamic Typeで、欠け・重なり・スクロール・主要操作の到達を確認。
- [ ] ライト・ダーク、通常経路と赤い線、色を識別しなくても使える文字・×。
- [ ] 地図通信を遮断し、目的地一覧・区間一覧・報告・保存・検索・音声へ到達。
- [ ] DeveloperModeの7回操作、3秒超えでのリセット、終了時の模擬・エラー停止。
- [ ] 明示ログ書き出しの内容に画像・位置履歴・軌跡が含まれない。

## 記録書式

実施日、担当、端末/OS、アプリ/道路/モデル版、実・模擬、場所、条件、操作、期待、実際、判定、未確認項目を記録。現時点の未実施チェックを成功に置き換えない。
