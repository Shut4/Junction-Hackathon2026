# 目的地付近までの道路経路（Issue #61）

従来は目的地への投影候補12件について「道路経路距離＋目的地までの直線距離」を比較したため、遠い道路で経路を打ち切り、残りを未確認の直線として表示することがあった。

目的地の最近傍の道路投影を先に確定し、その位置から1m以内で、投影距離の差も1m以内の候補だけを探索する。1mは接続点の同位置判定用であり、歩行可能性を保証する距離ではない。同一交差点の進入方向は候補に残す。通行不可や非接続の場合も、離れた道路の終点へ変更して成功とはしない。

目的地と道路終点の間を直線で描く点線は削除した。道路が通っている区間は既存の道路形状で案内し、建物中心のPOIと入口・通路の差は表示文で示す。目的地と終点が6m超離れている場合、終点到達時に「目的地に到着」とは読み上げない。

道路データに存在しない建物内の通路や入口は生成しない。目的地そのものまでの正確な案内には、入口座標と歩行可能な通路の収録が必要。出発位置から道路までの既存のapproach点線は今回の目的地接続とは別の処理で変更していない。

## 検証

DestinationRoadTestsは、回り道を直線で短縮しないこと、目的地側道路の閉鎖・分断時に遠い道路へ代用しないこと、実位置／道路外の出発点、交差点での同位置候補を検証する。

実データの回帰テストではApple Maps検索で得たソオカナの地点（33.8961473, 130.8410268）を使用した。最寄り道路との距離は約20.2m。従来の12候補からの最短経路選択より、目的地に近い道路終点まで道路形状に沿って到達することを確認する。検索結果の地点は施設入口の現地確認を意味しない。
